# Simple Inventory Management in C++

A basic C++ console application that manages a fixed-size product inventory. It allows adding new products, updating existing stock, removing quantities from inventory, and displaying the entire product list.

## Key Features  
- Supports up to 500 products.  
- Detects duplicate barcodes and increases stock automatically.  
- Prevents overflow by checking array capacity.  
- Simple console-based interaction with `getch()` prompts and screen clearing.

## Requirements  
- C++11 or higher  
- Console environment (Windows or compatible terminal)
